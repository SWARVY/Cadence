---
name: 재사용 전까지 인라인 유지 (YAGNI)
description: 5–10줄짜리 얇은 래퍼는 별도 파일로 분리하지 말고 호출 모듈 내부 함수로 인라인 (premature abstraction 회피)
type: feedback
---

`EmptyState` 같은 5–10줄짜리 얇은 래퍼는 파일을 따로 두지 않고 *호출 모듈 (주로 list 컴포넌트) 하단에 내부 함수* 로 인라인한다.

**Why:** "Three similar lines is better than a premature abstraction" 원칙. 추상화는 *볼륨 / 재사용 / 테스트 경계* 등 구체적 근거가 있을 때만 도입. 근거 없는 분리는 *역리팩터 비용* 으로 이어짐.

**How to apply:**

- 별도 파일로 분리 제안 시 반드시 근거 명시 — *재사용처 ≥ 2*, *자체 state / 훅 보유*, *테스트 경계 필요* 중 하나 이상
- 스펙시트 / 디렉토리 배치 작성 시 `empty-*.tsx` 같은 단일 파일을 *습관적으로* 넣지 말 것. 리스트 컴포넌트 설명에 "빈 상태 인라인" 으로 기재
- 기존 스펙 / 패턴을 복제할 때 *현재 코드베이스와 일치* 하는지 확인 — 과거 패턴이 이후 리팩터로 달라졌을 수 있음
