type: feedback
---

외부 도구가 같은 인증/세션 오류로 2회 실패하면 같은 세션에서 반복 재시도하지 않는다.

대상 예:

- Linear `token_expired` / `401`
- Figma 권한 또는 파일 접근 오류
- GitHub auth/session 오류
- browser/MCP 세션 stale 오류

보고 형식:

- 실패 도구 / 오류 코드
- 이미 완료한 확인
- 남은 확인 항목
- 재인증 또는 새 채팅 후 첫 액션

재인증 직후에도 같은 세션에서 실패하면 세션 캐시 가능성을 명시하고, 이어받기 요약을 만든 뒤 멈춘다.

이 룰은 네트워크 일시 오류를 무조건 포기하라는 뜻이 아니다. 같은 인증/세션 오류가 반복될 때만 적용한다.
